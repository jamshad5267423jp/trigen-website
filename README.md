# Trigen Interiors Website

Free static website for Trigen Interiors.

## Files
- `index.html` — website structure/content
- `style.css` — responsive styling

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, e.g. `trigen-website`.
3. Upload `index.html` and `style.css`.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will provide a free `github.io` address.
7. In Pages, add your purchased custom domain (e.g. `trigeninteriors.com`).
8. At your domain registrar, add the DNS records GitHub shows for the custom domain.

The site currently uses remote Unsplash photos as temporary portfolio imagery. Replace these URLs with your own project photos for the final site.
